# Decisiones pendientes

El documento de requisitos deja por decidir: generación local o API externa; versión oficial de Blender; prendas prioritarias; una prenda o conjuntos; malla estática o animable; límites finales de tamaño, resolución, duración WEBM, RAM, VRAM y tiempo; tecnología definitiva del visor 3D; calidad mínima de geometría y texturas.

Decisiones provisionales: Python 3.11 de 64 bits como base inicial; Tkinter como interfaz inicial; no fijar aún biblioteca de IA, CUDA ni modelo generativo; Blender se instala fuera de pip; temporales, resultados, modelos y logs quedan fuera de Git.
